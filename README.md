# health-risk-prediction-ml
A machine learning project to predict smoking and drinking habits based on health markers using classification algorithms

## 📁 Contents

- `mlproject.ipynb` - Main notebook with code, analysis, and visualizations.  
- `data/` - Directory to place the dataset (not included).  
- `models/` - Directory for saving trained models (if applicable).  

## 🚀 Getting Started

To run this project locally:

1. **Clone the Repository**  
   `git clone https://github.com/yourusername/mlproject.git`  
   `cd mlproject`

2. **(Optional) Create a Virtual Environment**  
   `python -m venv venv`  
   `source venv/bin/activate`  *(Windows: `venv\Scripts\activate`)*

3. **Install Dependencies**  
   `pip install -r requirements.txt`  
   If `requirements.txt` is missing, generate it with:  
   `pip freeze > requirements.txt`

4. **Launch Jupyter Notebook**  
   `jupyter notebook`
